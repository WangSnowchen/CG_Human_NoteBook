# 运动模糊异常的修复方法

## 现象

镜头渲染出的[[运动模糊]]不对：该糊的不糊（缓存缺 velocity）、不该糊的糊成一团（velocity 错误或姿势突变）、物体在模糊中穿插到别的物体里。

## 原因

- 缓存没有 `velocity` 属性，或 velocity 数值错误。
- 曝光期间几何姿势突变，子帧采样之间差异很大。
- 几何本身在子帧时刻和别的物体相交。

## 解决

[[lgtLib 共享节点库]] 里的五种修复：

1. **借速度**：从带正确速度的几何拷 velocity。

   ```text
   SubTree / Group（重挂成同名路径）
     → CopyPrimitiveVariables(primitiveVariables='velocity', ignoreIncompatible=True)
     → VelocityMotionBlur(motionUnit = Per Frame / Per Second, velocityScale 如 0.13)
   ```

2. **冻结姿势清掉坏模糊**：`TimeWarp(speed=0, offset=固定帧)` → `CopyPrimitiveVariables('P')`。曝光期间所有子帧的 P 都一样，velocity≈0，坏模糊消失。
3. **子帧位移修自穿插**：用 OSLObject 改 P，把辅助球范围内的点沿「离开相机」方向推开，只在子帧生效：

   ```c
   outP = transform("world", point(P));
   if (length(center - outP) < abs(radius)) {
       outP += normalize(outP - camera) * strength * (1 - length(center - outP)/abs(radius)) * 2 * abs(frame - round(frame));
   }
   outP = transform("world", "object", point(outP));
   ```

   - `abs(frame - round(frame))` 是关键：整数帧为 0（清晰帧不受影响），子帧按偏离整数帧的程度放大位移。
   - `center` / `radius` 由 `TransformQuery` 读辅助球的 translate / scale.x，`camera` 由 `OptionQuery` 读 `render:camera` 再取相机位置。辅助球做法见 [[Gaffer 视口辅助物]]。
4. **删掉错误的 velocity**：`DeletePrimitiveVariables` 只作用在 filter 选中的物体上。
5. **只在问题帧段应用修复**：节点上加 `frames` / `frameRange` 参数，Expression 算 `Switch.index`，见 [[Gaffer 按帧门控]]。

## 验证方法

渲问题帧和前后各一帧，对比模糊方向和长度；在 Viewer 里把上下文的 frame 设成子帧（如 1001.25）检查 P 的位移只在子帧出现、整数帧不变。
