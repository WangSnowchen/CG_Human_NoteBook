# X11 屏幕取色读到同一个灰色

## 现象

Linux / X11 下用 `XGetImage` 读屏幕像素做吸管（[[eyeDropper]]），不管光标在哪，读到的都是 `(30, 30, 30)`（[[来源 - Claude 全局记忆]]）。

## 原因

窗口管理器 KWin 是 OpenGL 合成器，各窗口的内容由合成器在 GPU 上合成，**根窗口本身的像素缓冲没有真实画面**，对根窗口 `XGetImage` 拿到的是无意义数据。`QScreen.grabWindow` 抓根窗口同样受影响。

## 解决

读光标下真正的客户端窗口：

1. `XQueryPointer( display, root, ... )` 拿到光标下的子窗口和根坐标。
2. 对子窗口继续 `XQueryPointer`，沿 reparent 链往下钻，直到没有子窗口（窗口管理器的装饰框会多套一层）。
3. 对这个客户端窗口 `XGetImage( win, 局部x, 局部y, 1, 1, AllPlanes, ZPixmap )`，从像素值里拆出 RGB。

整条链路用 ctypes 调 libX11 即可，本机实测通过。

## 验证方法

光标放在几个已知颜色的窗口上（纯红、纯白的画面），打印读到的值，确认随位置变化且和画面一致。
