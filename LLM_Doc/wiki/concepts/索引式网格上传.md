# 索引式网格上传

## 定义

GPU 上一个网格存成「唯一顶点表 + 索引表」，三角形通过索引引用顶点，共享顶点只存一份。与之相对的是无索引绘制（`glDrawArrays`），每个三角形的每个角各存一份顶点。

难点在 face-varying 属性（uv 接缝、硬边法线）：同一个位置在不同面上取值不同，必须拆成多个顶点。拆完后的顶点数相对原顶点数的倍数下文叫「拆分系数」。

## 在各软件里的对应

**[[IECoreGL]] 原生（`ToGLMeshConverter`）**：三角化后所有 primvar 提升成 FaceVarying、无索引绘制，视口网格约为源数据的 3 倍（[[来源 - Claude 全局记忆]]）。

**[[gaffer_indexed_mesh]]**：两种布局，按拆分系数自动选。

- **split**：唯一顶点的 key = (vertexId, 每个 FaceVarying primvar 的取值下标…, 每个 Uniform primvar 的面号…)。按顶点分桶、桶内线性比较去重；用哈希表实现会比原生转换慢 3 倍。
- **storm**：face-varying 数据放进 SSBO，另存一张角表，几何着色器按 `gl_PrimitiveIDIn` 取值。几何着色器让每帧慢一倍以上（render depth 8 整个场景强制 storm：0.076 → 0.184 s），所以只给拆分系数 > 1.5 的网格用；长仙村 render 网格的拆分系数只有 1.01。
- **法线**：linear 插值且没有 N 的网格不存法线。split 在 fragment 着色器 `main()` 开头用 `cross(dFdx(P), dFdy(P))` 算；storm 在几何着色器里叉乘。SSBO 里存的 N 要乘 `gl_NormalMatrix`。
- **只上传 `P,N,uv,Cs`**（`GAFFER_INDEXED_MESH_PRIMVARS`），int 型 primvar（如 `material_index`）一律丢掉。
- **打包**：N 用 10:10:10，uv 半精度，≤ 65535 顶点用 16 位索引；更大的网格分块后也用 16 位索引，见 [[顶点属性量化]]。
- **派生着色器**：覆写 `Primitive::shaderSetup()`，按着色器源码 hash 缓存，`addParametersToShaderSetup` 重新挂 uniform；编译方式见 [[IECoreGL 着色器预处理器不认 version 430]]。
- **顶点数据不交给 `Primitive` 基类**（基类会拷一份永远留在 CPU）：自己持有 `IECoreGL::Buffer`，`renderInstances()` 里按当前程序 `glGetAttribLocation` 自己绑定，上传后释放 CPU 那份，画完 `glDisableVertexAttribArray`。

效果数字见 [[Gaffer 视口展开大场景内存暴涨]]。

## 注意事项

- `MeshPrimitive::variableSize( Vertex )` 只数被面引用到的顶点，顶点数要按 P 的长度算。
- 团队的 USD 读取会保留长度为 0 的非法 primvar，转换前用 `isPrimitiveVariableValid` 过滤。
- 给每个顶点线性扫一遍面表是 O(n²)：373 万面的网格会让转换 100% CPU 卡死。先建好 face-varying → face 的对照表。
