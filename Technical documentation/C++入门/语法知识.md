	1.程序语言是什么
		人类语言是什么？
			中文、日文、英文、法文等。语言是用来人与人之间传递，交流信息的载体。供人与人之间沟通使用。
		程序语言是什么？
			用于人和计算机进行交流。通过程序语言让计算机能够响应我们发出的指令。
	2.常用的主流语言
		计算机语言的发展过程
			机器语言
				最早使用的计算机语言，由二进制代码也就是0和1组成。每条指令直接对硬件操作，编程难度极高且容易出错。
			⬇️
			汇编语言
				为了简化编程，汇编语言使用助记符代替复杂的二进制指令。它高度依赖硬件结构，需要程序员了解具体的计算机架构。汇编语言需要通过汇编器转换为机器语言才能被执行
			⬇️
			高级语言
				进一步简化编程过程，接近人类自然语言，比如C++、C#、Java都属于高级语言。但是本质上，高级语言还是需要通过编译器将代码“翻译”为机器语言进行执行。
		有很多种不同的高级语言
			C、C++、C#、Java、python、JavaScript、PHP、go、object-c、swift
		我们应该如何选择
			计算机有很多应用领域，不同程序语言有不同的擅长领域，所以就出现了一些流行的主流语言。
